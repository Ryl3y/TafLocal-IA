# TafLocal IA — Frontend

Application React + TypeScript (Vite).

```bash
npm install
cp .env.example .env   # VITE_API_BASE_URL=http://127.0.0.1:8000/api
npm run dev            # http://localhost:5173
npm run lint
npm run build
```

Voir le [README principal](../README.md) pour le backend et les comptes de démonstration.
